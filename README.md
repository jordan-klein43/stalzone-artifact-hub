## Overview

STALZONE Artifact Optimizer is a utility that runs in the browser and helps players assess artifact combinations in STALZONE. Its purpose is to make it easier to weigh alternative builds and find the ones that line up most closely with the stats you care about.

Reference values are drawn from the official STALZONE build calculator. You can use the live web demo to try out artifact arrangements, inspect the computed results, and tune a build toward specific stat priorities.

## FAQ

### How do I get started with the optimizer?

Load the [latest build](https://jordan-klein43.github.io/stalzone-artifact-hub/) in a web browser, supply the relevant artifact details, pick the stats you want to emphasize, and run the calculation.

### Is a game installation needed?

No. The web demo runs entirely through its browser interface, so no game install is required.

### How does it produce recommended combinations?

It checks the available artifact combinations against the desired stats you enter for the build and returns the combinations that fit those priorities.

### Can the target stats be changed?

Yes. The workflow starts with selecting the stats the build should prioritize, and comparisons are made against those choices.

### Where do the reference values originate?

The project relies on data from the official STALZONE build calculator. Results may reflect the limits and accuracy of that reference data.

### What happens when the project gets updated?

Visit the [latest build](https://jordan-klein43.github.io/stalzone-artifact-hub/) to get the currently published version. New data or changes to calculation behavior can alter the combinations shown.

### Is local use possible?

Yes. Download the repository files, serve them from a local web server, and open the resulting address in your browser.

### Where should local files go?

Keep the project files together in a single directory so the HTML interface can reach its related assets. The directory name does not matter as long as the file structure stays intact.
